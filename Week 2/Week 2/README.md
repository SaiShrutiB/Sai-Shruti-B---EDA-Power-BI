# Week 2 – Power BI

## Superstore Sales Dashboard

This project focuses on creating an interactive Power BI dashboard using the Superstore Sales dataset.

### Work Completed

- Prepared the Superstore Sales dataset using Power Query
- Created Customers, Products and Dim_Date dimension tables
- Established relationships using a Star Schema
- Created DAX measures for:
  - Total Sales
  - Total Profit
  - Total Orders
  - Total Quantity
  - Average Sales
  - Profit Margin %
- Designed KPI cards and interactive visualizations
- Added slicers for Year, Region, Category and Segment
- Created sales trend, regional performance, category performance and decomposition analysis visuals
