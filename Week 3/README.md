# Week 3 – Power BI

## Shopify Stock Market Dashboard

This project focuses on importing, transforming and analysing Shopify stock data using Power BI and DAX.

### Work Completed

- Imported and prepared the Shopify stock dataset
- Created a Date Table using the CALENDAR() DAX function
- Created a Year → Quarter → Month → Day date hierarchy
- Established a one-to-many relationship between the Date Table and stock data
- Created a separate Measures Table for organizing DAX measures
- Created financial measures for:
  - Open Price
  - Close Price
  - High Price
  - Low Price
  - Trading Volume
  - Daily Return %
- Created time-intelligence measures using:
  - DATEADD
  - TOTALYTD
  - SAMEPERIODLASTYEAR
- Designed an interactive stock-market dashboard
- Added drill-down analysis from Year → Quarter → Month → Day

### Dashboard Visuals

- Close Price Trend
- Open Price and Close Price Comparison
- Close Price and Previous Year Comparison
- Daily Return %
- Close Price YoY %
- Trading Volume
- Close Price YTD
