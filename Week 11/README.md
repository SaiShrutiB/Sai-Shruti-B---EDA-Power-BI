# Week 11 – Automobile Data Cleaning & Transformation

## Overview
This week, I worked on cleaning and preparing the automobile dataset using Power BI. The main focus was handling missing values, creating new columns, grouping vehicle information, and writing DAX measures.

## Work Done

- Imported the `Automobile_data.csv` dataset into Power BI.
- Replaced invalid `?` values with null values in Power Query.
- Changed the data types of horsepower, peak-rpm, and price to numeric.
- Created new columns:
  - Price per Horsepower
  - Power-to-Weight Ratio
  - MPG Rating Category
- Grouped vehicles by body style, drive wheels, and fuel system using the Group By option.
- Created separate summary queries to display vehicle counts for each category.
- Used conditional logic to handle missing values in the number of doors column.
- Created the following DAX measures:
  - Avg Price
  - Avg Horsepower
  - Avg Engine Size
  - Avg Highway MPG

## Tools Used
- Power BI Desktop
- Power Query
- DAX

## Outcome
Completed the cleaning and transformation of the automobile dataset, created additional vehicle-related columns, and prepared summary tables and measures for further analysis.
