# Power BI Week 6 – Healthcare Dashboard

##  Overview

This project focuses on creating DAX measures and an interactive healthcare dashboard using the data model prepared in Week 5. The dashboard was created to analyze patient information, medical conditions, admissions and billing details.

##  Objectives

- Create DAX measures for healthcare data analysis
- Calculate patient and billing-related metrics
- Analyze patient demographics
- Analyze medical conditions and admission types
- Compare billing amounts across insurance providers
- Create an interactive healthcare dashboard using slicers

##  Tools & Technologies

- Power BI Desktop
- DAX
- Power Query
- Healthcare Dataset
- Data Visualization

##  DAX Measures

The following measures were created for the dashboard:

- Total Patients
- Total Billing Amount
- Avg Billing Amount
- Avg Length of Stay
- Readmission Rate

These measures were stored in a separate Measures Table and used in different dashboard visuals.

##  KPI Cards

Four KPI cards were created to display the main summary values:

- Total Patients
- Total Billing Amount
- Average Billing Amount
- Average Length of Stay

These cards provide a quick overview of the healthcare data.

##  Patient Demographics

A matrix was created using Age Group, Gender and Medical Condition to analyze the distribution of patients across different demographic categories.

A donut chart was also created to show the number of patients in each age group:

- 0-18
- 19-35
- 36-60
- 60+

##  Medical Condition and Admission Analysis

A stacked bar chart was created to analyze Medical Condition by Admission Type.

The chart shows the number of patients under different admission types such as:

- Elective
- Emergency
- Urgent

##  Patient and Billing Trends

A Line and Stacked Column Chart was created to display Total Patients and Total Billing Amount over time.

This visual helps compare patient counts with billing amounts across different years.

##  Insurance Provider Analysis

A clustered column chart was created to compare Total Billing Amount across different insurance providers.

This helps in understanding the billing distribution among the insurance providers in the dataset.

##  Slicers

The dashboard includes the following slicers:

- Insurance Provider
- Admission Type
- Date of Admission

These slicers allow the dashboard to be filtered interactively based on the selected values.

##  Dashboard

The final dashboard combines cards, a matrix, donut chart, stacked bar chart, Line and Stacked Column Chart, clustered column chart and slicers.

The dashboard provides an overall view of patient demographics, medical conditions, admission types and billing information.
