# Week 12 – Automobile Analytics Dashboard

## Overview
In Week 12, I used the cleaned automobile dataset from Week 11 to create an interactive dashboard in Power BI. The dashboard focuses on comparing vehicle specifications, prices, manufacturers, and fuel efficiency.

## Work Done

- Created a Price Segment column to classify vehicles into Budget, Mid-Range, and Luxury categories.
- Created a Total Vehicles measure to display the total number of vehicle records.
- Added KPI cards to display:
  - Total Vehicles
  - Average Vehicle Price
  - Average Horsepower
  - Average Engine Size
  - Average Highway MPG
- Created scatter plots to analyse:
  - Engine Size vs Horsepower
  - Engine Size vs Highway MPG
- Created column charts to compare average vehicle prices by manufacturer and price segment.
- Compared highway mileage and average prices across different body styles.
- Created matrix visuals to analyse manufacturers, price segments, body styles, and horsepower.
- Created a separate Vehicle Details Tooltip page with vehicle specifications.
- Applied the custom tooltip to the scatter charts.
- Added slicers for manufacturer and price segment to filter the dashboard.

## Tools Used
- Power BI Desktop
- DAX
- Power Query

## Outcome
Created an Automobile Analytics Dashboard combining KPI cards, charts, matrices, custom tooltips, and slicers. The dashboard provides a way to explore and compare automobile manufacturers, prices, engine specifications, and fuel efficiency.
