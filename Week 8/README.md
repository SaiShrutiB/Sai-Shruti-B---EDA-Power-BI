# Power BI Week 8 – Student Performance Dashboard

##  Overview

This project focuses on building an interactive Student Performance Dashboard using Power BI. The dashboard analyzes academic scores across Math, Reading, and Writing and explores performance differences based on student background factors.

##  Objectives

- Analyze overall student academic performance.
- Compare average scores across subjects.
- Examine average scores by parental education level.
- Compare performance based on test preparation course and lunch type.
- Visualize student grade distribution.
- Add interactive slicers for data exploration.
- Create an Academic Profile page for student-level analysis using drill-through.

##  Tools & Technologies

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Student Performance Dataset
- Data Visualization

##  Dashboard Visualizations

### 1. KPI Cards

The dashboard includes KPI cards for key academic performance measures:

- Average Score
- Average Math Score
- Average Reading Score
- Average Writing Score
- Overall Pass %

These cards provide a quick summary of student performance.

### 2. Subject Performance Analysis

A clustered column chart compares average scores in Math, Reading, and Writing. It helps identify differences in performance across the three subjects.

### 3. Parental Education Analysis

A clustered bar chart compares students' overall average scores across parental education levels.

### 4. Test Preparation Analysis

A clustered column chart compares average scores between students who completed the test preparation course and those who did not.

### 5. Lunch Type Analysis

A clustered column chart compares overall average scores across lunch categories.

### 6. Grade Distribution

A donut chart displays the distribution of students across grades A, B, C, and F.

##  Interactive Slicers

The dashboard includes the following slicers:

- Gender
- Race/Ethnicity
- Parental Education
- Lunch Type
- Test Preparation Course
- Subject

These slicers allow users to filter the dashboard and explore different student groups.

##  Academic Profile – Drill-through

A separate report page named **Academic Profile** was created for student-level analysis.

The page includes:

- Average Score card
- Grade card
- Subject Performance chart
- Pass/Fail Result card
- Test Preparation card
- Student Details table

A Student ID drill-through field and a Back button were added to support navigation between report pages.

##  Key Analysis Areas

The dashboard supports analysis of:

- Differences in performance across subjects.
- Average scores across parental education categories.
- Performance differences based on test preparation.
- Average scores across lunch categories.
- Grade distribution among students.
- Student performance across demographic groups using slicers.
